# 배당·가치 자동매매 운용 규칙

공격형 BAA 60%, 배당·가치 40%. KODEX 200 스윙은 제거했습니다.
새 전략은 `portfolio.json`의 `dividend_value_orders_enabled=true`로 활성화합니다.
전체 봇의 기존 실전 환경·주문 허용·정규장·휴장일·미체결 확인 조건도 모두 적용됩니다.

- 종목검색: 매주 화요일 06:00 KST (월요일 21:00 UTC), 직전 완료 거래일 기준.
- 신규 매수: 화요일 09:10~14:30 중 완성된 당일 검색 결과를 확인하는 첫 봇 실행에서 주 1회.
- 정규 스크리닝은 검증 완료된 화요일 스냅샷으로 신규 매수를 시작합니다. 화요일 시작한 동일 주간 배치는
  수~금 정규장에서도 미매수·미체결 적격 종목의 가격, 잔고, 업종·위험 한도를 매 실행마다 재평가합니다.
  이미 체결된 종목·확정되지 않은 주문은 중복 제출하지 않으며, 금요일 최종 점검 뒤 종료합니다.
- 예외: **2026-11-10 1회 승인된 부분 검증 스냅샷**은 검증된 PASS 종목만 11월 10~13일 동안
  위 주간 배치 규칙으로 처리합니다. 미검증 REVIEW 종목을 매수하거나 다음 주로 이월하지 않습니다.
  미래의 다른 부분 검증·검색 실패 결과는 여전히 신규 매수를 차단합니다.
- 매도: 매매 가능한 각 봇 실행에서 신규 매수·BAA보다 먼저 확인합니다. 현행 시간당 실행을
  사용하며 장외·보고 전용 실행에서는 주문하지 않습니다.
- 확정 평균 체결가 대비 +15%에서 추적매도 활성화. 활성화 후 관측 최고가 대비 5% 이상
  하락하면 전량 매도합니다. 고정 익절은 없으며 +100%를 넘더라도 추적 조건에 따릅니다.
- 최고가·활성화·청산 의도를 주문 전에 영속 저장합니다. 재시작 후 확정 체결 원장으로
  보유량·평균 체결가를 복원하며 미확정 주문은 자동 재전송하지 않습니다.

신규 매수는 PASS 종목만 대상입니다. DART 보고 현금배당과 KIS PER/PBR/EPS/BPS를
기간·특별배당·분할·주식종류·감사의견·연결/별도 범위의 추가 검증 없이 사용합니다.
필수 자동조회 수치가 누락된 종목은 REVIEW이며, 조건 탈락 종목은 FAIL입니다.

첫 진입 예산은 전략 자산의 3%(계좌 NAV의 1.2%)입니다. 기업 4%, 최대 30종목,
업종 20%(DART 업종코드 앞 두 자리), 전략 현금 최소 10%, 거래대금 1% 한도와
배당 소득세 참고 수량 중 가장 작은 범위로 주문합니다. 현금 여유분을 추가 반영합니다.
기존 보유에 추가 매수하지 않고 같은 기업의 다른 주식 종류도 중복 진입하지 않습니다.
매수상한가 이하 지정가를 사용하며 브로커 매수가능수량을 다시 검사합니다.

매도 후 같은 종목은 20거래일간 재진입하지 않습니다. 매도 다음 거래일 재투자 규칙은
사용자의 최신 요청에 따라 **다음 적격 화요일**로 대체됩니다. 배당 삭감·자본잠식이
주간 공시 검사에서 확인되면 검토 알림을 남깁니다. 이 사유만으로 임의 청산하지 않습니다.

검색과 주문은 다른 프로세스입니다. 검색은 완성된 화요일 스냅샷을 전용
`dividend-signals` 브랜치에 발행합니다. 봇은 날짜·기준 거래일·실행 소스 커밋을 검증합니다.
부분 결과나 예전 코드의 결과로 신규 매수하지 않습니다. 주문/보유/주간 중복 방지 상태는
기존 `bot-state` 브랜치에 저장하고, BAA와 동일한 계좌 잠금·체결 대조 경로를 사용합니다.

검색 지연은 매도 실행을 막지 않습니다. 기존 예약 실행 간격 사이의 순간 최고가와 급락은
관측하지 못할 수 있으며, 거래소에 상시 스톱 주문을 두는 방식이 아닙니다. 실제 청산 가격은
갭·주문 지연에 따라 기준보다 낮을 수 있습니다.

병합 전 오프라인 회귀 및 읽기 전용 API 연결 검사를 수행합니다. 테스트를 위해 실거래
워크플로를 수동 실행하지 않습니다. 코드가 병합되어 운영에 배포되어야 자동 운용이 시작됩니다.

2026-11-01 KST [실제 API 연결 검사](https://github.com/ewqewq1234-ctrl/kis-30m-bot/actions/runs/41304635263)에서
KIS 시세와 OpenDART 기업정보 응답이 정상 확인되었습니다. 전체 조건검색 결과가 아니며,
그 실행에서 종목검색·계좌조회·주문을 수행하지 않았습니다.
